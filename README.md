# Data-Analyzer-Tool
An interactive Python and Streamlit application that automates data quality assessment, data cleaning, and exploratory data analysis (EDA). Features include missing value detection, outlier analysis, interactive visualizations, automated insights, data quality scoring, and downloadable HTML/PDF reports.

In Detail********

**Smart Data Quality Analyzer & Automated EDA Tool** is a Python-based application built using Streamlit that automates the process of data quality assessment, data cleaning, and Exploratory Data Analysis (EDA). It allows users to upload CSV, Excel, and JSON files and automatically analyzes datasets through an eight-stage pipeline.

The application identifies missing values, duplicate records, inconsistent data types, outliers, and invalid entries. It provides configurable data-cleaning options, interactive visualizations, statistical analysis, and automatically generated insights to help users understand their data more effectively.

One of its key features is a **Data Quality Score (0–100)** that evaluates datasets across five dimensions: completeness, consistency, validity, uniqueness, and accuracy. Users can compare data quality before and after cleaning and download detailed HTML/PDF reports along with cleaned datasets.

**Key Features:**

* Multi-format dataset upload (CSV, Excel, JSON, etc.).
* Automated data profiling and column-type detection.
* Missing value and duplicate detection.
* Outlier detection using IQR and Z-score methods.
* Automated data cleaning and type correction.
* Interactive EDA with statistical analysis and visualizations.
* Automatic insight generation using rule-based analysis.
* Overall data quality scoring (0–100).
* Before-and-after data quality comparison.
* Downloadable HTML/PDF reports and cleaned datasets.

**Technologies Used:** Python, Pandas, NumPy, Streamlit, Plotly, SciPy, ReportLab, RapidFuzz.

**Objective:** To simplify and automate the data preprocessing and exploratory analysis workflow, making dataset evaluation, cleaning, and understanding faster, more efficient, and accessible through an interactive interface.
